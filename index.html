ИНТЕГРАЦИЯ

Подключить Apify

Токен Apify хранится только на сервере в переменной APIFY_TOKEN. Actor по умолчанию — apify/instagram-scraper; его можно заменить через APIFY_ACTOR.

Что настроить на сервере
  1. Создайте токен в Apify → Settings → Integrations.
  2. Добавьте в .env: APIFY_TOKEN, при необходимости APIFY_ACTOR.
  3. Для фонового обновления задайте SYNC_INTERVAL_MS=21600000 (6 часов).

Теперь не нужно добавлять каждый рилс вручную: профиль импортирует последние публикации, а расписание обновляет сохранённые метрики. Ключ никогда не передаётся в браузер.
